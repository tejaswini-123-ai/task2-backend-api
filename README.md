# Users, Projects & Tasks REST API

A REST API built with **FastAPI** for managing users, projects, and tasks.

This project was developed as **Task 2 — Backend & REST API Development** for the Innovation Hacks Full Stack Development Internship.

---

## 🚀 Features

- User management with CRUD operations
- Project creation, retrieval, update, and deletion
- Task creation, retrieval, update, and deletion
- Task status management
- Input validation using Pydantic
- Centralized error handling
- Meaningful HTTP status codes
- Environment variable configuration
- Interactive API documentation using Swagger UI

---

## 🛠️ Technologies Used

- Python
- FastAPI
- Uvicorn
- Pydantic
- python-dotenv
